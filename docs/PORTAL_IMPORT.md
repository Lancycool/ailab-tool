# 学校实例导入验收

本次检查日期为 2026-10-25。

## 实现范围

本地面板通过仅限面板令牌的接口启动独立 Edge 窗口。用户在学校网站完成登录。一个工作线程负责整个浏览器会话，避免跨线程调用浏览器。程序只操作实例列表和连接信息弹窗。

平台适配器使用当前公开页面中的实例详情链接识别实例编号。适配器在对应表格行内寻找连接图标，不依赖自动生成的 CSS 类名。连接解析只接受 TCP、内部端口 22 和有效外部地址。多服务弹窗会逐个切换服务，多个 SSH 外部地址会作为候选项显示。

程序仅从正常页面响应中保留实例编号、名称和 expStopAt 字段。如果该字段不可用，程序保留剩余时间文本和读取时刻，按显示精度保守换算到期时间。程序不会绕过登录或主动修改平台资源。

## 真实平台检查

- 用户在程序打开的独立 Edge 窗口完成了登录。
- 程序识别到了现有实例和平台实例编号。
- 程序读取到“4天8小时19分”的剩余时间，显示为估算到期时间。
- 程序自动点击对应实例的连接按钮，并解析到与原 SSH 配置一致的外部主机和端口。
- 本地面板显示了导入预览。选择已有实例后，面板填入原来的用户名、工作目录、Conda 和 radar 环境。
- 面板只显示凭据引用，密码输入框保持空白。浏览器没有报告 JavaScript 错误。

本次真实检查没有保存覆盖原实例。保存流程使用隔离测试数据库和测试凭据进行验证，避免改变原实例的配置版本和批准记录。

本次共通过 58 项测试，包括原来的 37 项测试、新增 19 项导入测试和 2 项真实 Edge 测试。

新增检查覆盖地址与端口校验、仅导入 SSH 映射、多服务弹窗、准确与估算到期时间、敏感字段不保留、面板权限、同账号凭据复用、重复导入、旧实例关联、运行任务保护、失效会话、错误候选项和窗口关闭清理。

你可以执行普通测试：

```powershell

```

```powershell

.\.venv\Scripts\python.exe -m pytest -q
```

浏览器测试使用本地构造页面与隔离数据库，不要求学校账号。真实学校登录、验证码和平台页面变化仍需要人工配合检查。平台没有可解析的准确时间时，程序会明确使用估算值。

## 到期时间冲突修复

程序现在独立保存平台到期时间，并在保存实例时强制优先使用它。普通编辑接口不能删除或替换平台时间。新的有效平台读取可以更新旧值；旧读取结果和缺失时间的读取不能覆盖已经保存的新结果。程序可以从旧版本保存的剩余时间文本与读取时刻还原估算时间。

本次修复后，全部 66 项测试通过。新增的 8 项回归测试覆盖手动值早于或晚于平台值、导入后的手动编辑、平台续期或缩短期限、旧读取结果、读取失败、纯手动回退、旧版估算记录恢复和普通接口篡改来源。浏览器测试也确认平台时间在编辑表单中只读，而纯手动实例仍可编辑。

## 手动记录与平台导入去重

导入现在优先匹配平台身份；没有平台绑定时，程序按主机、端口和 SSH 用户名匹配手动记录。唯一匹配会沿用原实例编号和凭据。多个匹配会要求明确选择。不同账号、端口或平台编号不会自动合并。导入匹配与保存共用注册锁，避免并发导入生成两条记录。

已有重复记录的修复保留有训练历史的原实例编号。维护方法只处理重复记录没有任务或实验清单引用、两者工作目录和已确认主机指纹一致的情况。程序在一个数据库事务中归档两条原始配置，更新保留记录，并移除重复的活动记录。原任务、实验清单和结果文件不改写；有运行中任务时，程序拒绝合并。

本次完整测试共 77 项通过。新增 11 项检查覆盖自动复用手动编号、凭据保留、不同连接不合并、多候选处理、平台地址重新分配、归档恢复依据、历史引用及运行任务保护。浏览器测试确认面板会自动选中唯一匹配的手动记录。
