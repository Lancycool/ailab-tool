## Conda 报错与修复

此前配置中的 `/opt/conda` 和 `/home/user/.conda/envs/radar` 都是目录。旧程序直接把字段内容作为命令运行，所以 Linux 返回了 `PermissionError`。检查确认了用户可以访问这些目录，且 `/opt/conda/bin/conda` 可以正常执行。

程序现在会识别 Conda 安装目录，自动查找 `bin/conda` 或 `condabin/conda`。用户如果填入训练环境目录，程序会提示把该路径移到训练环境字段。程序也会分别报告文件不存在和文件缺少执行权限。远程操作报错不再一律把 SSH 标记为离线。

当前实例配置使用 `/opt/conda/bin/conda`，默认训练环境是 `radar`。面板新增了默认训练环境字段。Windows 服务停止脚本也已修正，避免只停止虚拟环境启动器、却留下仍在运行的旧服务子进程。
